EarlyFlow — a deterministic paper trading bot for the pump.fun replay. It buys only launches in their first few slots whose creator put a small amount of their own SOL in, whose crowd is already buying with sustained net inflow, and whose price has run up 1.2–2x from creation — then exits on take-profit, a trailing stop, a stop-loss, a time limit, a creator sell, or a flow reversal. Standard library only, no network, no clock, no randomness: the same replay always produces the same orders.

## Run it

```sh
node main.ts
```

The grader runs it as `node /bot/main.ts` (Node 22.18+ strips the TypeScript types). It speaks agent-fun/replay/v2 on stdin/stdout: one JSON line per batch in, one reply per batch out. See STRATEGY.md for the measured evidence behind the entry filters.
